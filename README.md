# Microsoft Fabric Lakehouse Demo

This repository documents a step-by-step implementation of a Microsoft Fabric Lakehouse solution. It covers the full process from workspace creation to data ingestion, SQL querying, and reporting with Power BI.

## 📁 Project Structure
- `sales.csv`: The source dataset used throughout the project.
- `screenshots/`: Step-by-step screenshots of the implementation.
- `README.md`: This document.

## ✅ Steps Followed

1. Create a Microsoft Fabric Workspace
2. Create a Lakehouse
3. Upload CSV data
4. Load data into a Delta table
5. Run SQL queries
6. Create visual queries
7. Build a Power BI Report

## 🔧 Technologies Used
- Microsoft Fabric (Lakehouse, Data Engineering, SQL Endpoint)
- Delta Lake Format
- Power BI
